# Un día a la vez — María C.

Prototipo web estático, en español y adaptable a celular. Inspirado en Villa Sofía y su entorno natural.

## Incluye

- Saludo y frase diaria para una guía flexible de 28 días; la app continúa después del día 28.
- Ideas flexibles de comidas y recetario de ejemplo.
- Favoritos guardados localmente.
- Pequeñas propuestas de bienestar.
- Lista diaria de cuidado general para los perros; nombres opcionales configurables.
- Preferencias opcionales guardadas solo en el navegador del dispositivo.
- Sin APIs, anuncios, pagos, suscripciones ni servicios externos.

## Probar

Abre `index.html` en el navegador. Para probar en teléfono antes de publicarlo, puedes pasar el archivo a ese dispositivo y abrirlo, aunque algunos navegadores restringen el almacenamiento local de archivos. La publicación en un alojamiento estático permite que funcione mejor como enlace web.

## Publicar gratis en GitHub Pages (manual)

1. Inicia sesión o crea una cuenta de GitHub.
2. Crea un repositorio nuevo. Si se va a publicar, elige la visibilidad pública solo si estás de acuerdo con que cualquiera pueda abrir el sitio.
3. Sube `index.html` a la raíz del repositorio (el archivo debe llamarse exactamente `index.html`). Puedes subir también este `README.md`.
4. En el repositorio, abre **Settings → Pages**.
5. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama principal (por ejemplo `main`) y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio y abre el enlace que muestre en esa misma sección.

Los nombres de los menús podrían variar si GitHub actualiza su interfaz. Antes de ponerlo público, revisa el contenido y la visibilidad del repositorio. Esta app guarda sus datos localmente en cada navegador: no sincroniza entre dispositivos y los datos pueden perderse al borrar los datos del navegador.

## Nota de salud y privacidad

Las recetas e ideas son generales y no sustituyen orientación de un profesional de salud. Si María C. está perdiendo peso sin proponérselo o le preocupa su salud, que consulte con un profesional. No añadir datos médicos, dirección exacta ni información sensible. El código no transmite información a un servidor; cualquier dato guardado por la app queda en el almacenamiento local del navegador.
